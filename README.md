# ocr-lens

Перевод текста на экране поверх оригинала, как в Google Lens. Выделяете область — текст распознаётся (Tesseract) и переводится прямо на скриншоте.

## Как переводит

| Режим | Движок | Скорость |
|---|---|---|
| Есть интернет | Google Translate (бесплатно, без ключа) | ~0,2–0,5 с |
| Нет интернета | Локальная LLM: Qwen2.5-3B через llama.cpp | ~4–10 с, первый запуск ~20 с |

Переключение автоматическое: если Google недоступен или режет запросы, ocr-lens переходит на локальную модель, а через ~20 с (после блокировки — через 2 минуты) пробует Google снова. После перевода вверху экрана показывается, кто переводил: «Перевод: Google» или «Перевод: локальная LLM».

Локальная модель грузится в память только когда нужна и выгружается после 5 минут простоя; пока интернет есть, она не занимает ОЗУ.

## Установка

```bash
git clone https://github.com/SRtaui/ocr-lens.git
cd ocr-lens
./install.sh
```

Установщик:
- поставит системные пакеты (pacman / apt / dnf / zypper);
- предложит скачать локальную LLM для офлайн-режима (llama.cpp ~20 МБ и модель ~2 ГБ в `~/.local/share/ocr-lens`). Без неё онлайн-перевод работает как обычно, а без интернета перевода не будет: `./install.sh --no-llm` пропускает этот шаг;
- предложит хоткей `Ctrl+Alt+O` (Hyprland или Sway).

Python-пакеты из pip не нужны: демон перевода использует только стандартную библиотеку.

## Использование

| Клавиша | Действие |
|---|---|
| ЛКМ, тянуть | выделить область и перевести |
| Space | оригинал / перевод |
| C | скопировать перевод |
| Esc / ПКМ | закрыть |

## Требования

- Wayland-композитор с поддержкой layer-shell и screencopy: Hyprland, Sway, river, niri, KDE Plasma 6 (частично). GNOME и X11 не поддерживаются.
- Для локальной LLM: x86_64 или aarch64, ~3 ГБ свободной ОЗУ и ~2 ГБ на диске. Используется готовая сборка llama.cpp для Ubuntu; на очень старых дистрибутивах она может не запуститься.

## Замечание про Google

Онлайн-режим использует бесплатную неофициальную точку Google Translate без ключа. Она может измениться или начать ограничивать запросы, тогда ocr-lens продолжит работать через локальную модель.

## Удаление

```bash
./install.sh --uninstall
```
